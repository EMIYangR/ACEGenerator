# ACE 赛事生成器

#### 输出效果

##### 标准四局升分制输出

``` wikitext

|M1={{Match|finished=
    |p1=0
    |twitch=|youtube=
    |map1={{Map|date=November 29, 2026 - 19:00 {{Abbr/CST}} |finished=|vod=}}
    |map2={{Map|date=November 29, 2026 - 19:40 {{Abbr/CST}} |finished=|vod=}}
    |map3={{Map|date=November 29, 2026 - 20:20 {{Abbr/CST}} |finished=|vod=}}
    |map4={{Map|date=November 29, 2026 - 21:00 {{Abbr/CST}} |finished=|vod=}}
    |opponent1={{SoloOpponent|Test 1|flag=cn
        |m1={{MS|1|p=10}}|m2={{MS|1|p=20}}|m3={{MS|1|p=20}}|m4={{MS|1|p=30}}
```

#### 使用指南

##### 1. 选择输出部分

「控制项」一行是七个复选框。只勾选要填写并导出的部分；未勾选的部分既不显示，也不写入结果。lab 阶段「积分」复选框不可选，积分固定使用预设。

| 控制项 | 输出内容 |
| --- | --- |
| 标题 | `Mxheader` 行 |
| 比赛 | 比赛状态、`\|pX=` 与直播流占位行 |
| 积分 | 手动填写 `p1`–`p6`（lab 阶段不可用） |
| 晋级 | `\|bg=` 排名分段与状态 |
| 游戏局数 | 时间、状态与局数 |
| 录像 | 每局 `\|vod=` 与对应文本框 |
| 选手 | 名称、地区与每局排名 |

##### 2. 选择积分规则

- **单局制**——每局共用同一张积分表（`10 / 7 / 5 / 3 / 2 / 1`）。
- **四局升分制**——四张循环表：`M1` 10 / 7 / 5 / 3 / 2 / 1，`M2` 与 `M3` 20 / 14 / 10 / 6 / 4 / 2，`M4` 30 / 21 / 15 / 9 / 6 / 3；后续各局按此循环。
- **添加比赛**在末尾追加一张比赛卡片。
- 切换规则或修改排名时都会重算积分。lab 阶段不支持自定义积分，手动积分框不可用。

##### 3. 导入模板

- **模板导入**——粘贴比赛模板的文本框，也可以直接全选复制整页内容粘贴。
- **导入模板**——解析文本并替换当前比赛列表。
- 「模板导入」右侧的箭头折叠或展开文本框与按钮。
- **清空**——清空导入框与提示文字。
- 生成器不处理的行（外层模板、章节标题、注释、额外参数、`|footer=end`、带值的直播流行）会保留在结果中。要从空列表开始，保持导入框不变，使用「添加比赛」。

##### 4. 填写标题与比赛状态

- **标题**输入框位于比赛头部，填入 `Mxheader`。
- 「比赛」下拉框只有设为「已结束」时才输出 `finished=true`。任何状态变更都会同步到该场比赛的所有局；把「已结束」改回「未进行」或「进行中」时会弹出确认提示：回退比赛状态可能导致已经结束的比赛的状态显示错误。
- **删除比赛**删除该卡片；删掉最后一张时会自动补一张空白比赛。
- 比赛卡片头部的右侧箭头折叠该比赛；「选手排名」右侧的箭头折叠选手表格。
- 只要勾选了「比赛」，即使 `|pX=` 和直播流占位行没有对应的 UI，也始终会输出。

##### 5. 填写游戏局数与时间

- 卡片操作栏依次是**添加 / 删除 4 局**（单局制下为 1 局）、**添加 / 删除 6 人**，以及两个复选框：**自动填充**、**中场休息**；勾选状态即开关状态。
- 「游戏数据」行的样式与「选手排名」一致，包含**时区**、**游戏局数**两个输入框，以及由上面两个开关控制显隐的间隔输入框。
- **时区** 按比赛手动输入（例如 `CST`），只有填入时间后才会写成 `{{Abbr/CST}}`。
- 勾选「自动填充」后显示**自动填充间隔（分钟）**（1–240），按该间隔把首局时间顺延；修改某一局会重算后续局。取消勾选后隐藏该输入框并停止自动填充。
- 勾选「中场休息」后显示**中场休息间隔（分钟）**（默认 10），并在每个四局组的第 2、3 局之间额外加上这段时间；取消勾选后隐藏该输入框并取消额外间隔。
- 对局表格标题栏为：**游戏局数 / 比赛时间 / 比赛状态 / 比赛录像**；每行以 G1…Gn 标注，标题居中。
- 「游戏数据」行右侧有折叠箭头，与选手表格一致；**全部展开 / 全部收起**也会一起处理。
- 每一局都有原生时间选择控件、状态下拉框，以及删除该局的 `×` 按钮。只有勾选「录像」时才显示 **VOD** 文本框；取消勾选后输出中不再包含 `|vod=`。

##### 6. 填写选手

- **添加 / 删除 6 人**按六人改变选手数量，「选手数量」框也可手动填写。
- 选手表头把「选手」与「地区」拆成两个居中列，对局列为 G1…Gn；生成的 wikitext 仍使用 `|mN=`。
- 每名选手一行，含序号、名称、地区代码（默认 `cn`）与逐局排名输入；积分按预设表自动填入。
- 行末的 `×` 按钮删除该名选手。

##### 7. 导航与提示

快速导航栏在滚动时保持置顶；右下角的悬浮按钮回到页面顶部。左列是提示卡片，以及一段无边框的纯文本信息（项目链接、「最近更新」与 LICENSE 链接）。页面使用 Bootstrap 和 jQuery。

- `M1…Mn` 按钮跳到对应比赛并自动展开。
- **全部展开 / 全部收起**一次性展开或收起所有比赛与选手表格。
- **↑ 顶部**回到页面顶部。
- 窄屏下提示块固定在页面顶端且默认折叠：点 **☰ 提示** 展开，再点一次收起。
- 提示内容包括 lab 阶段不支持自定义积分、当前处于早期版本，以及预设积分规则。
- 「最近更新」记录最近的改动（当前为「修复了一些已知问题。」），以纯文本行显示，不带方框。

##### 8. 导出与清空

结果随输入实时更新。「生成结果」右侧的箭头折叠或展开结果区域。

- **复制**复制结果。
- **下载 .txt** 保存为 `ACE-template.txt`。
- **选手输出格式**切换单行与每轮（四局）换行；选手列始终补空格对齐。
- **清空 Cookies** 删除本站 Cookies 并重置语言。
- **清空本地数据** 清空本地存储并重置语言。
- **中文 / EN** 切换中英文。两个清空按钮都会把界面切回英文。
