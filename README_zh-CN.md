# ACE 赛事生成器

#### 使用指南
##### 1. 选择输出部分

「控制项」一行是五个复选框。只勾选要填写并导出的部分；未勾选的部分既不显示，也不写入结果。

| 控制项 | 输出内容 |
| --- | --- |
| 标题 | `Mxheader` 行 |
| 比赛 | 比赛状态、`\|pX=` 与直播流占位行 |
| 积分 | 手动填写 `p1`–`p6` |
| 游戏局数 | 时间、VOD 与局数 |
| 选手 | 名称、地区与每局排名 |

##### 2. 选择积分规则

**单局制**每局共用同一张积分表；**四局升分制**按 4 局增减，并使用四张循环表，切换规则或修改排名时都会重算积分。只有勾选「积分」时，手动积分框才会显示。

##### 3. 导入模板

在「模板导入」里粘贴比赛模板，点击「导入模板」。导入会替换当前比赛列表。要从空列表开始，保持导入框不变，使用「添加比赛」。

##### 4. 填写标题与比赛状态

「标题」填入 `Mxheader`。「比赛」下拉框只有设为「已结束」时才输出 `finished=true`。只要勾选了「比赛」，即使 `|pX=` 和直播流占位行没有对应的 UI，也始终会输出。

##### 5. 填写游戏局数与时间

**添加 / 删除 4 局**（单局制下为 1 局）改变局数，数量框也可手动填写。填入第一局时间后，「自动填充后续」会按「间隔（分钟）」顺延；修改某一局会重算后续局。「时区」按比赛手动输入，只有填入时间后才会写入输出。

##### 6. 填写选手

**添加 / 删除 6 人**按六人改变选手数量，数量框也可手动填写。逐局填写每名选手的名称、地区与排名。

##### 7. 折叠与跳转

比赛卡片头部的右侧箭头折叠该比赛；「选手排名」右侧的箭头折叠选手表格。快速导航栏可跳到 `M1…Mn` 并自动展开目标，也可整体展开或收起。

##### 8. 导出与清空

结果随输入实时更新。「复制」复制结果，「下载 .txt」保存文件。「清空 Cookies」与「清空本地数据」重置浏览器状态，两者都会把界面切回英文。页眉按钮切换中英文
